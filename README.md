# Midterm project: Block Bootstrap to estimate the downfall of an investment portfolio [![Slides and report render](../../actions/workflows/check-qmd-render.yaml/badge.svg)](../../actions/workflows/check-qmd-render.yaml)

The repository contains several files:

- `README.md`: this file.
- `data`: The dowloaded historical return of selected financial instrument
- `.gitignore`: a file that tells git which files to ignore.
- `slides.qmd`: a presentation in quarto format.
- `report.qmd`: a report in quarto format.
- `.github/workflows/check-qmd-render.yaml`: The workflow that builds the html and pdf files.
