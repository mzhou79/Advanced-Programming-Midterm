Introduction

Stock investors commonly hold portfolios containing a combination of exchange-traded funds (ETFs) and individual stocks. Understanding the risks associated with these portfolios is essential for making informed investment decisions.

Traditional financial risk analysis often relies on measures such as historical volatility (eg. beta, which measures a stock’s volatility or systematic risk compared to the broader market) or standard deviation. Although useful, these measures have important limitations. Financial returns can exhibit volatility clustering, extreme losses, and dependence across assets, particularly during market downturns.

Thus, the central question motivating this project is: Given a portfolio’s composition and historical market behavior, how severe could its future losses become?

For the midterm part, I’m going to use three most common ETF to demonstrate my method: QQQ (tracks NASDAQ), VOO (tracks SP500), SCHD (a famous ETF by Charles Schwab that includes some best companies with high dividends).

Simulation

#' @param returns Is a vector ....
#' @param weights 
riskpath_sim <- function(returns, weights,
                         initial_value,
                         horizon,
                         n_sim,
                         block_size) {

# Input validation - making sure that there are no errors in the return data
stopifnot(
    is.numeric(returns),
    all(is.finite(returns)),
    ncol(returns) == length(weights),
    all(weights >= 0),
    abs(sum(weights) - 1) < 1e-8,
    block_size >= 1,
    block_size <= nrow(returns),
    horizon >= 1,
    n_sim >= 1)
  
  #if (!is.numeric(returns))
  #stop("The variable `returns` is not numeric.")
  # assertthat package
  
  n <- nrow(returns)
  n_blocks <- ceiling(horizon / block_size)

# Store simulated portfolio values into a matrix. I have to add an additional line because of day0 is the starting value.
  paths <- matrix(
    NA_real_,
    nrow = horizon + 1,
    ncol = n_sim
  )
  
  paths[1, ] <- initial_value
  

  
# Begin the simulation loop
  for (s in seq_len(n_sim)) {
    
# Sample starting positions for blocks (you have to have block_size consectutive days, so the maximum is n-block_size+1)
    starts <- sample.int(
      n - block_size + 1,
      n_blocks,
      replace = TRUE
    )
    
# Construct one simulated return sequence
    # unlist: combine everything into ONE vector
    # lapply: produce a list of returns, starting from the selected starting day, lasting n_block
    idx <- unlist(lapply(
      starts,
      function(i) i:(i + block_size - 1)
    ))
    
# Turncate into the number of horizon
    idx <- idx[seq_len(horizon)]

# Extract the simulated daily ETF return from the real data    
    sim_returns <- returns[idx, , drop = FALSE]
    
# Calculate the portfolio's daily return by weights
    portfolio_returns <- as.vector(
      sim_returns %*% weights
    )
    
# Calculate portfolio value over time by the cumulative product function *cumprod*
    paths[-1, s] <- initial_value *
      cumprod(1 + portfolio_returns)
  }
  
  return(paths)
}

Calculate the estimands of interest

First calcualte the loss: \[ Loss=1-\frac{V_{terminal}}{V_{initial}} \] Ranges from 0-1. The bigger indicates the more loss.

Then we calculate the esitmands of intererst:

  1. Value at risk (VaR): [confidence] percentage of the simulated scenarios have a terminal loss no greater than the number got.

  2. Expected Shortfall (ES): The average loss among the worst simulated outcomes.

  3. Maximum drawdown (MD): The average of the largest decline in portfolio value for all the simulations

  4. Probability of exceeding a [threshold] percentage decline

# Calculate
riskpath_metrics <- function(paths,
                             confidence = 0.95,
                             threshold = 0.20) {
  
# Terminal portfolio losses
  losses <- 1 - paths[nrow(paths), ] / paths[1, ]
  
# Value at Risk
  VaR <- unname(quantile(losses, confidence))
  
# Expected Shortfall
  ES <- mean(losses[losses >= VaR])
  
# Maximum decline, apply for each simulation
  MD <- apply(paths, 2, function(p) {
    max(1 - p / cummax(p))
  })
  
  list(
    VaR = VaR,
    ES = ES,
    mean_max_decline = mean(MD),
  # The probablity that the decline exceed the [threshhold]
    probability_20pct_decline =
      mean(MD >= threshold)
  )
}
